# A05 browser capture origin proposal

The existing supply policy is `planning/qualification/supply/licenses.json`; its
schema is enforced by `scripts/conformance/supply/license-gate.js`. Each PNG needs
an exact path/SHA-256, origin, allowed license, retained license text and a notice
present in `THIRD_PARTY_NOTICES.md`. The gate walks qualification sources, so moving
these files does not waive this requirement. This batch adds declarations for
these 44 A05 screenshots to the existing catalog. The separate oracle license gate has a narrower scope.

`png-origins-proposed.json` provides 44 proposed catalog rows, with the exact raw
report/session hashes and observed browser identities alongside the required
fields. The same rows are included in the catalog for machine validation, explicitly
marked `proposed-maintainer-review`; this is not human review or sign-off. Failed
sessions remain failed evidence; a capture origin does not establish a passed test.

- 36 captures show, or attempted to show, the official Speedscope 1.24.0 UI. The
  recorded release commit is `fc76932551754a442cd5c4f0afdba28032d14d8a`; the ZIP's
  SHA-256 is `1cd7de1f33e7a56a0b08ca51b4ba9598b766676f9c5f07077e731258d47e6121`.
  Its unchanged MIT license (copyright 2018 Jamie Wong) is retained in
  `licenses/speedscope-MIT.txt`. Its 1,067 bytes match the recorded asset manifests
  and the pinned upstream source LICENSE exactly by SHA-256
  `6244b13e9bf25cfd42d81c939d6c535d932596e8c320050234f2c2ac5a6f36a0`.
- Eight captures are the repository-authored CSP fixture generated by
  `tests/fixtures/a05-browser/server.py`, with the repository MIT license. Each
  proposal points to its exact recorded source revision and capture evidence.

The UI release uses Source Code Pro. Its exact 4,485-byte OFL 1.1 text is retained
as `licenses/source-code-pro-OFL.txt`, with SHA-256
`2e14ee65e55dbcc7d66347cd7c76a10a1a18ac49dd7989a2b3838b479676f746`, matching
the recorded release manifests. The OFL's preamble and condition 5 expressly state
that its font licensing requirement does not apply to documents created using the
font. These PNGs are rendered captures; the relocation includes no font binary or
Speedscope application distribution. The proposed classification is MIT for the
UI/repository content, with the font source notice retained for traceability. It
does not relicense font software, assert browser-vendor ownership, or confer an
upstream endorsement.
