# Typed template catalog

Project and item plans preserve the released example identifiers and contain all generated records, folders and optimistic project edits. `TemplateCatalog` is an explicit installation scope; `searchTemplates` searches its metadata without changing the built-in registry.

`normalizeTemplateOptions` validates framework, nullable state, implicit usings, explicit Main, namespace style, output type and solution layout. `templateAvailability` reports a native or Windows prerequisite separately from generation. Native test packages remain pinned; importing templates never restores them.

The native WinUI test template is an actual executable whose XAML App owns the UI thread and MSTest/MTP runner. It propagates test exit codes and closes its window. Windows compilation and execution remain unqualified on Linux. The native library includes a XAML control with a matching partial class.

The XML edit dependency preserves comments and formatting and keeps expectedText preconditions. Archive dynamic DEFLATE supplies deterministic PNG assets for native app manifests.
