# SHA-256 allocation reduction

The shared CIL/symbols implementation now reads full blocks from the caller's
read-only view. Only the final 64 or 128 padded bytes are copied. The 64-word
schedule and eight-word state are reused; block iteration allocates no arrays
or callbacks. Time is O(input bytes), scratch space O(1). Input limits, digest
ownership and synchronous browser/worker behavior are unchanged.

Node 24.21.0, Apple M3 Pro, macOS ARM64; 31 samples, sequential baseline then
changed implementation. The machine was shared, with one local validation job.
Raw results are in [sha256-node24.json](./sha256-node24.json).

| Input | Median µs before → after | p95 µs before → after | Sampled heap delta bytes | Sampled ArrayBuffer delta bytes |
| --- | --- | --- | --- | --- |
| 64 KiB | 1038.05 → 280.07 | 1070.92 → 289.58 | 329480 → 1840 | 65888 → 352 |
| 1 MiB | 16322.42 → 4552.42 | 16711.71 → 4787.19 | 1056888 → 1856 | 1048928 → 352 |

Memory values are median deltas around one warm hash call after explicit GC,
not peak memory or cumulative allocation. Tiny-input ArrayBuffer deltas in the
raw report can be negative as prior samples are reclaimed. No whole-compiler
speedup or cross-platform performance claim is made.

Run the changed implementation through the repository's resource limiter:

```sh
SHARPFORGE_TEST_CONCURRENCY=1 SHARPFORGE_MAX_PARALLEL_RUNS=1 \
  node scripts/limited.js node --expose-gc packages/cil/tools/benchmark-sha256.mjs working-tree
```

The baseline is commit `681db84fc428af04d4b779dd5a25d82afc586101`.
To reproduce it, copy the benchmark into an isolated checkout of that commit
at the same relative path and run the same command. The recorded run used a
minimal temporary snapshot of that commit's `src/binary/hash.js` and this
benchmark, with `type: module`; no product dependencies are required.

Validation: 49 focused tests passed, including every padding boundary, offset
Buffer inputs, a million-byte native-crypto comparison and Portable PDB consumers.
Static/syntax checks passed; no new structure findings.
