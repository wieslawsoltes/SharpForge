# Ordinary CIL example

`Arithmetic.dll` is generated by `npm run examples:managed` using the hand-authored CIL fixture builder, not the C# compiler/emitter. It has no #SF stream and no entry point. Methods: Add(int,int), Square(int), Hello(). There is no native code or external payload.

Open it in Assembly Explorer; select Add and pass [20,22] to return 42. Edit the `add` instruction to `mul` in Edit IL and pass [6,8] to return 48. The accompanying .sf.il file is the editable all-body representation. These examples test no-#SF behavior, not third-party Roslyn/CLR interoperability.
